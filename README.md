# KD-Tree in C++ and openMP

## Overview

This project implements a k-d tree, a space-partitioning data structure for organizing points in a k-dimensional space. 

## Features

- **Point Insertion**: Efficiently insert points into a k-d tree.
- **Nearest Neighbor Search**: Quickly find the point closest to a given target point.
- **Range Search**: Retrieve all points within a specified range.
- **Tree Visualization**: Print the structure of the k-d tree to visualize its layout.

## Compilation and Execution

1. **Compile the Program**
   ```bash
   g++ -o KDTree KD_Tree.cpp -fopenmp
   ```

2. **Run the Program**
   ```bash
   ./KDTree
   ```
